# Guaranteed Saplings Minecraft Datapack

Guaranteed Saplings is a Minecraft Java Edition datapack that replaces leaf block loot tables to guarantee a matching sapling or mangrove propagule from eligible leaves, including leaves broken with shears or Silk Touch, leaves destroyed by decay, and leaves destroyed by explosions.

## Install

1. Locate the world folder for your Minecraft Java Edition 26.2 world.
2. Copy the `sapling-chance-datapack` folder into the world's `datapacks` folder.
3. Start or restart the world, or run `/reload`.
4. Run `/datapack list` to confirm that the datapack is enabled.

## Use

Break or allow supported leaf blocks to decay. Each eligible leaf block provides one matching sapling or mangrove propagule when the drop survives the explosion condition.

Supported tree types are oak, spruce, birch, jungle, acacia, dark oak, mangrove, cherry, and pale oak.

Leaves drop as blocks only when broken with shears or a tool containing Silk Touch. Leaves destroyed by decay or explosions do not drop as blocks. The datapack guarantees drops per eligible leaf block and does not inspect the complete tree shape.
